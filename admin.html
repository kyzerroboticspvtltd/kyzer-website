☁️ Supabase Setup (cross-device sync)

Supabase syncs your admin changes to all devices instantly — no backend server needed. The free tier is plenty for this site.

Setup steps:
1. supabase.com → Project Settings → API → copy Project URL + anon key
2. SQL Editor → run the SQL below (sets up table + secure RLS)
3. Authentication → Users → Add user → enter your email + a strong password
4. Paste credentials above and into supabase-config.js in your site folder
Show one-time setup SQL → 
CREATE TABLE IF NOT EXISTS site_data (
  id INTEGER PRIMARY KEY DEFAULT 1,
  products JSONB DEFAULT '[]',
  categories JSONB DEFAULT '[]',
  hero JSONB DEFAULT '{}',
  services JSONB DEFAULT '[]',
  contact JSONB DEFAULT '{}',
  links JSONB DEFAULT '{}',
  quote JSONB DEFAULT '{}',
  hero_photos JSONB DEFAULT '[]',
  print_orders JSONB DEFAULT '[]',
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
INSERT INTO site_data (id) VALUES (1) ON CONFLICT DO NOTHING;
ALTER TABLE site_data ENABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "public_read" ON site_data;
DROP POLICY IF EXISTS "auth_write" ON site_data;
DROP POLICY IF EXISTS "read_all" ON site_data;
DROP POLICY IF EXISTS "write_all" ON site_data;
CREATE POLICY "read_all"  ON site_data FOR SELECT USING (true);
CREATE POLICY "write_all" ON site_data FOR ALL    USING (true) WITH CHECK (true);
💳 Razorpay Payment Gateway

Enables real online payments on the checkout page. Use test keys while testing — swap to live keys when ready to accept real payments.

Setup steps:
1. Sign up at dashboard.razorpay.com
2. Settings → API Keys → Generate Test Key
3. Copy the Key ID here (starts with rzp_test_)
4. Put the Key Secret in your backend .env as RAZORPAY_KEY_SECRET
Use http://localhost:3000 while developing locally.
