Settings

Integrations, site mode, and account. Publishing and order updates are handled securely on the server — no secret keys are stored in this browser.

☁️ Supabase (cross-device sync)

Supabase syncs your catalog, orders, and customers across all devices. These are the public read credentials — the secret service key lives only on the server, so it's safe if this browser is shared.

Leave blank to use the built-in defaults. This key can only read data — it cannot modify anything.

CREATE TABLE IF NOT EXISTS site_data (
  id INTEGER PRIMARY KEY DEFAULT 1,
  products JSONB DEFAULT '[]',
  categories JSONB DEFAULT '[]',
  hero JSONB DEFAULT '{}',
  services JSONB DEFAULT '[]',
  contact JSONB DEFAULT '{}',
  links JSONB DEFAULT '{}',
  quote JSONB DEFAULT '{}',
  hero_photos JSONB DEFAULT '[]',
  coming_soon JSONB DEFAULT NULL,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
INSERT INTO site_data (id) VALUES (1) ON CONFLICT DO NOTHING;
ALTER TABLE site_data ADD COLUMN IF NOT EXISTS coming_soon JSONB;
ALTER TABLE site_data ENABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "public_read" ON site_data;
DROP POLICY IF EXISTS "auth_write" ON site_data;
DROP POLICY IF EXISTS "read_all" ON site_data;
DROP POLICY IF EXISTS "write_all" ON site_data;
-- Allow anyone to read (needed for customer site)
CREATE POLICY "read_all" ON site_data FOR SELECT USING (true);
-- No write policy for anon = writes blocked
-- Service role key bypasses RLS automatically

-- ── 3D PRINT ORDERS TABLE ──
CREATE TABLE IF NOT EXISTS orders (
  id TEXT PRIMARY KEY,
  submitted_at TIMESTAMPTZ DEFAULT NOW(),
  status TEXT DEFAULT 'new',
  data JSONB NOT NULL DEFAULT '{}'
);
ALTER TABLE orders ENABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "customers_insert_orders" ON orders;
DROP POLICY IF EXISTS "read_orders" ON orders;
CREATE POLICY "customers_insert_orders" ON orders FOR INSERT TO anon WITH CHECK (true);
CREATE POLICY "read_orders" ON orders FOR SELECT USING (true);

-- ── SHOP ORDERS TABLE ──
CREATE TABLE IF NOT EXISTS shop_orders (
  id TEXT PRIMARY KEY,
  submitted_at TIMESTAMPTZ DEFAULT NOW(),
  status TEXT DEFAULT 'new',
  data JSONB NOT NULL DEFAULT '{}'
);
ALTER TABLE shop_orders ENABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "customers_insert_shop_orders" ON shop_orders;
DROP POLICY IF EXISTS "read_shop_orders" ON shop_orders;
CREATE POLICY "customers_insert_shop_orders" ON shop_orders FOR INSERT TO anon WITH CHECK (true);
CREATE POLICY "read_shop_orders" ON shop_orders FOR SELECT USING (true);

-- ── QUOTE INQUIRIES TABLE ──
CREATE TABLE IF NOT EXISTS quote_inquiries (
  id TEXT PRIMARY KEY,
  submitted_at TIMESTAMPTZ DEFAULT NOW(),
  status TEXT DEFAULT 'new',
  name TEXT, email TEXT, phone TEXT, org TEXT,
  project_type TEXT, description TEXT, timeline TEXT, budget TEXT
);
ALTER TABLE quote_inquiries ENABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "qi_insert" ON quote_inquiries;
DROP POLICY IF EXISTS "qi_read" ON quote_inquiries;
CREATE POLICY "qi_insert" ON quote_inquiries FOR INSERT TO anon WITH CHECK (true);
CREATE POLICY "qi_read"   ON quote_inquiries FOR SELECT USING (true);

-- ── CUSTOMERS TABLE ──
CREATE TABLE IF NOT EXISTS customers (
  id TEXT PRIMARY KEY,
  name TEXT,
  email TEXT UNIQUE,
  phone TEXT,
  address JSONB DEFAULT '{}',
  created_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE customers ENABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "customers_insert" ON customers;
DROP POLICY IF EXISTS "customers_read" ON customers;
CREATE POLICY "customers_insert" ON customers FOR INSERT TO anon WITH CHECK (true);
CREATE POLICY "customers_read" ON customers FOR SELECT USING (true);

💳 Razorpay Payment Gateway

Enables real online payments on the checkout page. Use test keys while testing — swap to live keys when ready to accept real payments.

Setup steps:

2. Settings → API Keys → Generate Test Key
3. Copy the Key ID here (starts with rzp_test_)
4. Add the Key Secret as RAZORPAY_KEY_SECRET in your Vercel environment variables

🔒 Account & Security

Your admin password is stored securely on the server, never in this browser. To change it, update the ADMIN_PASSWORD environment variable in your Vercel project settings, then redeploy. Everyone is signed out automatically when the password changes.
